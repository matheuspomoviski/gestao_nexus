# Gestão Nexus
Esse projeto está sendo desenvolvido ao longo do curso de Desenvolvimento de Sistemas no Senac sendo feito com foco para o uso desktop e contendo MySQL e Java. O desenvolvimento é individual e todo processo está sendo feito apenas por mim.
## Objetivo
Minha ideia é criar um software para gestão de estoque, onde independente do tamanho do setor da empresa, se possa controlar os insumos para produção e futuramente contar com um modelo de I.A para automatizar processos de pedido de compra
## Linguagens
Dentro do curso é obrigatoriamente usar MySQL e Java como linguagem de programação. A intenção é que eu consiga usar essa base para que eu possa usar Java para estruturar uma API e que ela sirva para alimentar o front-end em uma aplicação web
